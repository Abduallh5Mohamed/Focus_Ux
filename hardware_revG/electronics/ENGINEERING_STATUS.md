# RevG electronics — actual design status and ERC/DRC

Date2026-10-30. Native `FOCUS_RevG_Mainboard_REVIEW.kicad_pro/.kicad_sch/.kicad_pcb` and source generator exist. They are a **partial subsystem/interface review drawing**, not a complete mainboard design. The placement canvas is210x180mm, deliberately bench sized and wholly unsuited to eyewear. There are no released Gerbers.

Implemented review-level elements: four IM69D130 PDM microphone symbols with shared clock and two data-pair buses/SELECT strapping; a TPA2016D2 analog-amplifier draft with floating BTL pair headers, candidate attenuation/coupling, default-low SDZ pulldown and external hard-mute input; headers for off-board host, external supplies, DAC and supervisor; probe pads. These drawn nets are **not** proof of the complete electrical/thermal/audio system.

Critical missing circuits: exact P4 host SKU and support, USB2512B hub topology and power switching, B0441 interface, actual A7670E/SIM/RF circuit/ESD, battery pack/protection, BQ25895 charger/USB-C, complete modem/digital/USB power stages, fuel gauge, codec/DAC, clock/memory, independent output limiter and an actually designed default-safe supervisor. The hard mute input is a control node; its presence does not itself set an output power limit. External supplies have no safety/sequence details.

**Manual electrical review finding:** the TPA2016D2 schematic generator inserts extra `REVIEW_UNSPECIFIED` pins16 and20 and an exposed-pad symbol21 without manufacturer pin-function approval, and uses a generic QFN footprint that must be checked against the RTJ land pattern. [TI pin-function table](https://www.ti.com/lit/ds/symlink/tpa2016d2.pdf) specifies RTJ QFN pins1–15 and17–19 as functional; pins16/20 are absent from that table. Do not use this drawing to assemble an amplifier until symbol/footprint/NC handling and all grounds/decoupling are reviewed. The presented attenuation values also are only provisional, not a safe bone-output threshold. Input acoustic ports and mic supply/clock routing require real board layout.

Automated checks were run on the **current partial files** with KiCad10 CLI; see `reports/ERC.rpt` and `reports/DRC.rpt`. After normalizing `sym-lib-table`, the rerun reported **49 ERC violations** and **4 DRC hole-clearance violations plus 91 unconnected pads**. In particular, the four mic footprint NPTH/pad clearances need review, and the PCB has no completed routing. These are failures, not suppressed warnings. Passing checks after future fixes would still not prove operating electronics.

Before a complete RevG PCB: lock verified component footprints/datasheets/variants; draw all missing power and RF reference circuits; name all power sources and test points; conduct safety/current/limiter reviews; run ERC; place/rout stackup appropriate to USB and RF; run DRC; review manufacturing DFM; prototype and bench-test. Do not export fabrication files before those steps. Existing RevA KiCad files are a separate Pico button carrier only.
